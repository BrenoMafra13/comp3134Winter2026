Mystery Task 1 Report

- What you see on the browser (the issue): 
The page displays a PHP Warning: "scandir(hello): Failed to open directory: No such file or directory".
This happens because the script is trying to list a folder that does not exist in the current directory.

- What sensitive information is given by this page: 
The error message reveals the full server-side file path: "/var/www/html/directory_traversal_part1.php". 
This is considered sensitive information disclosure because it helps an attacker understand the server's 
directory structure and plan more targeted Directory Traversal attacks.
